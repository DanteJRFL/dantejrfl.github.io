# Dante Junior — Portfolio

Portfólio reconstruído com React, TypeScript, Vite, Tailwind CSS, Motion e Lucide React.

## Requisitos
- Node.js 20 ou superior
- npm

## Executar localmente
```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

## Gerar build
```bash
npm run build
npm run preview
```

## Publicar no GitHub Pages
1. Crie um repositório para o projeto.
2. Ajuste `base` em `vite.config.ts`:
   - Para repositório `usuario.github.io`, use `/`.
   - Para repositório de projeto, use `/nome-do-repositorio/`.
3. Execute `npm run deploy`.

## Personalização
- Projetos e tecnologias: `src/data.ts`
- Conteúdo, seções, idioma e interações: `src/App.tsx`
- Estilos: `src/styles.css`

Os dados de formação, links e contatos foram preservados da base enviada e devem ser revisados antes da publicação.
